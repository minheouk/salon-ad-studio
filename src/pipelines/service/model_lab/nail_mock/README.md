# 이달의 아트 모델 실험실

`index.html`을 열면 이미지 생성, 글 생성, 한 번에 생성 탭에서 목업 결과를 확인할 수 있습니다. 매장명, 인스타그램 아이디, 영업시간, 예약 링크, 프롬프트, 사진은 모두 선택이며 입력은 탭 사이에서 공유합니다. 인스타그램 아이디 앞의 @는 요청에서 제거합니다. 예약 링크는 http 또는 https 절대 URL을 입력하고, 첨부 사진은 JPG와 PNG를 사용합니다. 실험 결과와 요청 입력 기록은 탭별로 표시됩니다.

## 실행 및 전달

저장소 루트에서 아래 명령을 실행합니다. 실험 페이지는 `src/pipelines/service/model_lab/nail_mock/index.html`에 있고, `assets/`의 예시 이미지 두 장을 상대 경로로 참조합니다. 파일을 직접 열어 목업을 볼 수도 있습니다. API 연동과 결과 이미지 파일을 포함한 다운로드는 HTTP로 실행해 확인합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory src/pipelines/service/model_lab
```

브라우저에서 `http://127.0.0.1:8765/nail_mock/`을 엽니다.

## 목업으로 실험하는 방법

1. 이미지 생성, 글 생성, 한 번에 생성 중 하나를 탭에서 고릅니다.
2. 매장 정보와 프롬프트를 입력하고 사진을 첨부합니다. 일부만 입력하거나 모두 비워도 생성할 수 있습니다. **예시 입력**은 매장 정보와 프롬프트를 채웁니다.
3. 생성 버튼을 눌러 결과를 확인합니다. 서버 주소를 설정하기 전에는 예시 결과를 표시합니다. 탭을 바꿔도 입력은 공유되고 결과는 탭별로 쌓입니다.
4. **요청 입력 보기**에서 실행 당시의 입력을 확인합니다. **실험 기록 다운로드**로 JSON을 저장하고 **실험 기록 불러오기**로 입력·사진·모드를 복원한 뒤 다시 실행할 수 있습니다. 개별 삭제와 결과 초기화는 실험 기록을 정리할 때 사용합니다.

## 모델 서버 연결

먼저 [API 명세의 AI(백 - 모델) 탭](https://docs.google.com/spreadsheets/d/1W98YYAuxcuiWkDYRTW-1GSuWUvfxa46Vk8d0J77EFus/edit?gid=882937156#gid=882937156)에서 **AI-01 · 이미지 생성**과 **AI-03 · 글 생성**의 요청 필드와 예시를 확인합니다. 동일한 요청 필드를 사용하면 모델팀이 실험 환경과 실제 서비스에서 같은 입력 구조를 활용할 수 있습니다.

1. [model-client.js](model-client.js)의 `modelEndpoints.image`에 이미지 서버의 POST URL을, `modelEndpoints.text`에 모델팀이 확정한 글 생성 POST URL을 넣습니다. 예를 들어 로컬 AI 서버가 8000번 포트에서 AI-01 경로로 실행되면 이미지 URL은 `http://127.0.0.1:8000/generate`입니다.
2. 서버 응답 형식이 아래 실험 페이지 형식과 다르면 같은 파일의 `requestGeneration`에서 변환합니다. AI-01과 AI-03의 응답 영역은 모델팀이 실제 구현에 맞춰 상태 코드, 필드, 성공·오류 예시를 작성합니다. AI-03의 경로도 모델팀과 확정합니다.
3. 페이지와 API의 출처가 다르면 AI 서버에서 실험 페이지 출처(예: `http://127.0.0.1:8765`)의 CORS 요청을 허용합니다. 인증이 필요하면 웹 백엔드 프록시에서 처리하고 브라우저 소스에는 서버 비밀 키를 넣지 않습니다.
4. 페이지를 새로고침하고 연결한 유형의 탭에서 생성합니다. 연결 표시가 **API 연결 모드**로 바뀌는지 확인하고, 브라우저 개발자 도구의 네트워크 탭에서 POST 주소와 응답 상태를 확인합니다. URL을 다시 비우고 새로고침하면 해당 유형은 목업으로 돌아갑니다.

`modelEndpoints.image`가 비어 있으면 목업에서 예시 이미지 두 장을 표시합니다. 이미지 생성 엔드포인트를 설정하면 서버가 응답의 `images`에 담아 반환한 이미지를 표시합니다. 연결된 API의 요청이 실패하면 오류 메시지를 표시합니다.

`modelEndpoints.text`가 비어 있으면 글 생성은 목업으로 동작합니다. **한 번에 생성**은 같은 입력으로 이미지·글 요청을 동시에 보내고, 성공한 쪽의 결과를 표시합니다.

### 요청 필드와 검증

두 API 모두 `POST`, `multipart/form-data`를 사용합니다.

| 필드 | 타입 | 실험 | 예시 |
| --- | --- | --- | --- |
| `shop` | string | 선택 | 오라네일 |
| `instagramId` | string | 선택 | ora_nail |
| `businessHours` | string | 선택 | 화~일 11:00–20:00 / 월 휴무 |
| `booking` | URL 문자열 | 선택 | https://example.com/reserve |
| `prompt` | string | 선택 | 겨울 느낌의 이달의 아트를 만들어 주세요. |
| `images` | file[] | 선택 | JPG 또는 PNG를 같은 키로 반복 전송 |

- **실제 서비스 명세**에서는 매장명, 인스타그램 아이디, 영업시간, 예약 링크와 네일 이미지(JPG 또는 PNG) 최소 1장이 필수입니다. 프롬프트는 선택입니다.
- **실험 페이지**에서는 여섯 항목 모두 비워서 실행할 수 있습니다. API 연결 시 빈 텍스트 필드는 빈 문자열로 보내고, 사진을 첨부하지 않으면 `images` 키를 생략합니다. 입력한 인스타그램 아이디는 앞의 `@`를 제거합니다. 예약 링크와 사진의 형식 검증은 값을 입력하거나 파일을 첨부했을 때만 적용합니다.

API 연결 후 AI-01 엔드포인트를 호출하는 예시입니다. 글 생성도 같은 필드를 사용하며 POST 주소는 모델팀과 확정합니다.

```sh
curl http://127.0.0.1:8000/generate \
  --form-string 'shop=오라네일' \
  --form-string 'instagramId=ora_nail' \
  --form 'images=@/path/to/nail.jpg;type=image/jpeg'
```

### 목업의 응답 예시

아래는 현재 화면이 표시할 수 있는 예시입니다. 서버의 확정 응답에 맞춰 변환할 수 있습니다.

이미지 생성

```json
{"images":[{"url":"https://example.com/nail-tips.png","label":"네일 팁 가격표"},{"url":"https://example.com/collage.png","label":"착용컷 콜라주"}]}
```

글 생성

```json
{"caption":"이달의 아트를 소개합니다.","hashtags":"#이달의아트 #네일아트"}
```

## 실험 기록 다운로드

각 결과의 **실험 기록 다운로드**에서 JSON을 저장할 수 있습니다. 실행 시각, 생성 모드, 입력값, 원본 첨부 사진, API 주소 및 목업 여부, 생성 결과와 오류를 포함합니다. 사진 파일은 data URL로 포함하며, 브라우저에서 읽을 수 없는 결과 이미지는 서버에서 받은 URL을 기록합니다.

**실험 기록 불러오기**에서 같은 JSON을 선택하면 매장 정보, 프롬프트, 원본 첨부 사진, 생성 모드가 복원됩니다. 생성 버튼을 눌러 다시 실행할 수 있습니다. 다시 실행할 때는 현재 설정된 API 주소를 사용합니다.
