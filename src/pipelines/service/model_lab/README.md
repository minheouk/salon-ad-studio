# 광고 모델 실험

사진과 프롬프트를 바꿔가며 광고 이미지의 생성·수정 결과를 비교하는 팀 내부 실험 페이지입니다. 실험 서버는 OpenAI 이미지 API를 호출하며, 실제 서비스와 별도로 실행합니다.

## 내 실험 브랜치에 목업 가져오기

`feat/service-model-lab`이 원격에 올라간 뒤, 본인의 모델 실험 브랜치에서 아래 명령을 실행합니다. 먼저 `git status --short --branch`로 현재 브랜치를 확인합니다. 이미 `src/pipelines/service/model_lab/`에 작업한 파일이 있다면 가져오기 전에 해당 변경을 백업합니다.

```sh
git fetch origin
git restore --source=origin/feat/service-model-lab -- src/pipelines/service/model_lab/
```

현재 브랜치에서 목업 폴더만 작업 트리에 가져옵니다. 가져온 뒤 아래 실행 절차를 따르면 됩니다. 목업 브랜치를 체크아웃하고 있다면 바로 실행 절차로 넘어가면 됩니다.

정적 네일 목업의 실행 방법과 글 생성·실험 기록 기능은 [네일 모델 실험실 안내](nail_mock/README.md)에서 확인할 수 있습니다.

## 실행하기

1. Python 3.10 이상을 사용합니다. 저장소 루트의 기존 `.env`에 `OPENAI_API_KEY`가 설정되어 있는지 확인합니다. 셸 환경에 같은 변수가 설정되어 있으면 서버는 그 값을 우선 사용합니다.
2. 저장소 루트에서 서버를 실행합니다. 이 서버에는 별도의 Python 패키지 설치가 필요 없습니다.

   ```sh
   python3 -m src.pipelines.service.model_lab.server
   ```

3. 로컬에서 실행했다면 브라우저에서 [실험 페이지](http://127.0.0.1:8516/model-lab/)를 엽니다. 서버를 종료하려면 실행한 터미널에서 `Ctrl+C`를 누릅니다.

VM에서는 본인 작업 폴더에서 같은 모듈을 실행하되, `--port`에 [팀 VM 가이드의 본인 화면 포트](../../../../docs/vm_member_guide.md#3-포트-내-번호만-쓰기)를 지정합니다. VS Code Remote SSH의 포트 전달을 사용하면 본인 PC 브라우저에서 전달된 로컬 주소의 `/model-lab/`을 열 수 있습니다.

## 생성하고 수정하기

1. **이미지 생성 모델**을 선택하고 프롬프트를 입력합니다. 범용·텍스트 임베딩 모델 선택은 현재 이미지 요청에 반영되지 않습니다.
2. 참고 사진이 있으면 **사진 첨부**를 누르거나 입력창에 파일을 끌어다 놓습니다. JPG와 PNG를 첨부할 수 있고, 미리보기의 `×`로 전송 전에 첨부를 해제할 수 있습니다.
3. **보내기**를 눌러 첫 이미지를 생성합니다. 예를 들어 제품 사진을 첨부하고 “제품이 중앙에 보이도록 밝은 배경의 정사각형 광고 이미지를 만들어 주세요”라고 입력합니다.
4. 결과가 나오면 “제품과 구도는 유지하고 배경만 밝은 파란색으로 바꿔 주세요”처럼 변경할 내용을 입력하고 **수정 요청**을 누릅니다. 직전 결과는 자동으로 첨부되며, 필요한 경우 참고 사진을 추가할 수 있습니다.
5. 이전 결과와 비교해 제품과 구도가 유지됐는지, 배경이 요청대로 바뀌었는지 확인합니다. 필요한 결과는 **저장하기**로 PNG를 내려받습니다. **새 실험**을 누르거나 페이지를 새로고침하면 화면 기록이 초기화됩니다.

## 실험 결과 비교하기

- 모델을 비교할 때는 같은 사진과 프롬프트로 새 실험을 시작하고 모델만 바꿉니다.
- 프롬프트를 비교할 때는 모델과 사진을 고정하고 프롬프트만 바꿉니다. 직전 결과가 다음 수정에 들어가므로, 같은 이미지에서 여러 수정안을 비교하려면 동일한 원본을 기준으로 실험합니다.
- 공유할 때는 선택한 모델, 입력 프롬프트, 참고 사진, 결과 PNG, 관찰한 점을 함께 기록합니다.

## 문제가 생겼을 때

- **페이지가 안 열립니다** — 서버 터미널에 표시된 주소와 포트를 확인합니다. VM이라면 VS Code의 포트 전달 상태도 확인합니다. 포트가 사용 중이면 실행 명령 끝에 `--port <포트 번호>`를 붙입니다.
- **전송 버튼을 누를 수 없습니다** — 이미지 생성 모델을 선택하고 프롬프트를 입력했는지 확인합니다. 생성·수정 중에는 요청이 끝날 때까지 기다립니다.
- **생성·수정 요청이 실패합니다** — 화면 메시지와 서버 터미널의 오류를 확인합니다. 시작할 때 키 오류가 나면 저장소 루트의 `.env` 또는 셸 환경을 확인합니다.
