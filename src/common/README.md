# src/common (공용 계약)

역할 사이에 주고받는 **데이터 형식과 공통 설정**을 두는 곳입니다.
예를 들어 서비스 화면이 서빙 API에 보내는 요청 형식, 서빙이 모델에서 받아 돌려주는 결과 형식이 여기에 들어갑니다.

여기를 바꾸면 다른 역할의 코드가 함께 깨질 수 있습니다. 그래서 변경 절차가 따로 있습니다.

## 변경 절차

1. 디스코드에서 영향을 받는 역할에 먼저 알립니다.
2. PR의 **"⚠️ PM 확인 필요 → 공용 파일 변경"**에 체크하고, 무엇이 왜 바뀌는지 적습니다.
3. **PM이 승인하고 merge**합니다.
