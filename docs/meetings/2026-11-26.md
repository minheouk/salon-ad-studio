- 투명한 장식이 있는 네일을 인식하지 못하는 문제를 수정합니다.

- 로그인 기능 등 서비스에 필요한 와이어프레임을 만듭니다.

### 모델 서빙

- API 명세 작성을 마쳤고, 실험으로 확인이 필요합니다.
- 서버 제한 시간과 이미지 생성 시간을 확인한 뒤 조정합니다.
- 가능하면 백엔드와 연결하는 실험을 진행합니다.
